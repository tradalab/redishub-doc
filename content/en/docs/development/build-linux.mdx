# Building for Linux

Linux artifacts (`.AppImage`) are built natively with the `scorix` CLI - no Docker required.
Packaging the AppImage needs `linuxdeploy` and the GTK/WebKit dev libraries.

## Prerequisites

- **Go 1.27**, **Node.js 24** and **pnpm 11.22.0** - see [Getting Started](/docs/development/setup)
- **AppImage tooling** - `linuxdeploy` plus `build-essential`, `pkg-config`, `file`, `patchelf`, `squashfs-tools`, `libgtk-3-dev`, `libwebkit2gtk-4.0-dev`, `libfuse2`
- **scorix CLI** - install the version pinned in `go.mod`, not `@latest`; see
  [Getting Started](/docs/development/setup)

These are the packages CI installs on its `ubuntu-22.04` runner:

```bash
sudo apt-get install -y \
  build-essential pkg-config file patchelf squashfs-tools \
  libgtk-3-dev libwebkit2gtk-4.0-dev libfuse2
curl -fsSL -o /usr/local/bin/linuxdeploy \
  https://github.com/linuxdeploy/linuxdeploy/releases/download/continuous/linuxdeploy-x86_64.AppImage
chmod 755 /usr/local/bin/linuxdeploy
```

## Build Process

From the project root:

```bash
make package          # scorix package - builds the binary + wraps it into an AppImage
```

Or invoke `scorix` directly to target an explicit OS/arch (this is what CI runs):

```bash
scorix package -d . --os linux --arch amd64
```

## Output Locations

- `artifacts/RedisHub-<version>-linux-amd64.AppImage` (version tracks `app.version` in `scorix.yaml`)

This AppImage runs directly on any modern Linux distribution without installation.

> [!NOTE]
> CI runs the same `scorix package` step on a native `ubuntu-22.04` runner. `.github/workflows/release.yml`
> calls the reusable `scorix-release.yml` from `tradalab/scorix`, which builds every target in
> `scorix.yaml` as one matrix when a `v*` tag is pushed.
