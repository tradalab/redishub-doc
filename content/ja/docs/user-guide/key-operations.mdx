# キー操作

RedisHub の直感的なデータブラウザーを使って、データを簡単に閲覧・管理できます。

## キーブラウザー

キーブラウザーでは、glob パターン（例: `user:*`）を使ってキーを検索・絞り込みできます。

### キーの閲覧
- ドロップダウンからデータベースインデックスを選択します（デフォルトは 0〜15）。
- 検索バーを使って、名前でキーを絞り込みます。glob パターン（例: `user:*`）に対応しています。
- キーをクリックすると、その詳細と値が表示されます。
- **大規模データ対応**: 50 万件以上のキーを持つデータベース向けに最適化されており、高負荷なインスタンスでもスムーズなツリー描画と即時の検索結果を提供します。

## データの編集

RedisHub は主要な Redis データ型をすべてサポートしています。

### 文字列（String）
プレーンな文字列値を表示・編集できます。複数の表示モード（Text、JSON、Hex）に対応しています。

### JSON（RedisJSON）
RedisJSON ドキュメント（`ReJSON-RL`）を直接閲覧・編集できます。開くと整形表示され、編集して **保存** を押すとドキュメント全体が書き戻されます。不正な JSON はサーバーに送る前に拒否され、キーは文字列に変換されず JSON ドキュメントのまま保たれます。
- **作成**: 新規キーのダイアログで型に **JSON** を選択します。
- **絞り込み**: キー型フィルターで **rejson-rl** を選ぶと JSON ドキュメントのみが一覧されます。
- **必要条件**: RedisJSON モジュールを備えた Redis サーバー。Redis 8 は本体に同梱、Redis 7 では `redis-stack` が必要です。

- **値がたまたま JSON である通常の文字列とは異なります。そちらは `string` キーのままで、文字列エディタの JSON 表示モードで開きます。**

### グラフ（RedisGraph / FalkorDB）
`graphdata` キーは値エディタではなく **Cypher コンソール** で開きます。グラフには表示すべき単一の値が存在しないためです。クエリを入力して **実行**（または `Ctrl+Enter`）を押すと、結果を 2 通りの方法で確認できます。
- **グラフ**: 対話的なノードリンク表示。ドラッグで移動、スクロールで拡大縮小、ノードにホバーまたはクリックすると隣接ノードが強調され、プロパティが表示されます。結果が大きい場合は 300 ノードで打ち切られ、その旨がバッジで示されます。
- **テーブル**: サーバーが返した行と列をそのまま表示します。ノードとリレーションは JSON として描画されます。

ヘッダーにはグラフのノード数とリレーション数、含まれるラベルとリレーションタイプが表示され、いずれかをクリックすると対応するクエリがエディタに入力されます。
- **作成**: 新規キーのダイアログで型に **GRAPH** を選び、グラフを作成する Cypher を入力します。
- **絞り込み**: キー型フィルターで **graphdata** を選ぶとグラフのみが一覧されます。
- **必要条件**: グラフモジュール。RedisGraph は 2023 年にサポートを終了しており、[FalkorDB](https://www.falkordb.com/) が保守されているフォークで、同じコマンドに対応しています。

### ハッシュ（Hash）
フィールドと値のペアを表形式で管理します。個々のフィールドの追加、編集、削除ができます。

### リスト（List）
リストの要素を順序どおりに表示します。先頭または末尾への要素追加に対応しています。

### セット（Set）
セットのユニークなメンバーを管理します。

### ソート済みセット（ZSet）
メンバーと、それに関連付けられたスコアを管理します。

### ストリーム（Stream）
ストリームのエントリを、その ID とフィールドと値のペアとともに閲覧できます。

## 共通の操作
- **キーの削除**: データベースからキーを削除します。
- **一括削除**: プレフィックスを指定して、複数のキーを一度に削除します。個別にキーを削除するよりもはるかに高速で、Redis サーバーをブロックしないように最適化されています。
- **キーのリネーム**: キーを安全にリネームします。
- **TTL の設定**: キーの有効期限（Time To Live）を設定または更新します。
