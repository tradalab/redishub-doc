# インターフェースとタブ

RedisHub は、生産性の高いマルチタスクのために設計された、モダンなタブベースのインターフェースを備えています。このレイアウトにより、複数のアクティブな接続を維持しながら、作業中の状態を失うことなく異なる操作コンテキストを切り替えられます。

## タブナビゲーション

タブバーはアプリケーションの上部に配置され、主要なナビゲーションの拠点として機能します。

### コアタブ
- **Connections Dashboard**: サーバー、グループ、SSH トンネルを管理するためのホーム画面です。
- **Key Browser**: データベースに接続すると表示されます。各ブラウザータブは特定の接続に紐付けられます。
- **Settings**: サイドバーからアクセスでき、アクティブなブラウザーを閉じることなくアプリケーションを調整できます。

## 複数の接続の操作

RedisHub は、多数のアクティブな接続を同時に扱えるように構築されています。

1. **Simultaneous Browsing**: 異なる Redis インスタンス（例: 開発、ステージング、本番）に対して複数のブラウザータブを開けます。
2. **Tab Isolation**: 各タブは、独自のデータベース選択、検索結果、スクロール位置を保持します。

## UI インジケーター

- **Active State**: 現在フォーカスされているタブは、インディゴ色の下線でハイライトされます。
- **Loading Indicators**: 長時間実行されるコマンド（深い `SCAN` など）の進行中は、タブに控えめなローディングスピナーが表示されます。
- **Validation Dots**: その特定のコンテキストで接続の問題や検証エラーがある場合、タブにインジケーターが表示されます。

## Web モードのサポート

バージョン 1.9.0 以降、RedisHub は中央集約型の Web アプリケーションとしてデプロイできます。これは、各マシンにネイティブクライアントをインストールすることなく、あらゆるブラウザーからアクセスできる共有 Redis 管理コンソールを求めるチームに最適です。

Web バージョンの設定とデプロイの詳細な手順については、**[Web モード デプロイガイド](/docs/user-guide/web-mode)**を参照してください。

## タブの管理

- **Closing Tabs**: タブの **x** アイコンをクリックすると閉じます。これにより、その接続の UI コンテキストが安全に終了されます。
- **Reordering**: タブをドラッグ＆ドロップして、現在のワークフローに合わせてワークスペースを整理できます。

## 専用ツール

RedisHub には、Redis インスタンスの監視とデバッグに役立ついくつかの専用ツールが含まれています。

### Monitor
**モニター**ツール（サイドバーから利用可能）は、Redis サーバーが処理するすべてのコマンドをリアルタイムでストリーミングします。
- **Real-time Visibility**: サーバーに届いているコマンドを正確に把握できます。
- **Filtering**: キーワードでストリームをフィルタリングし、特定の操作を見つけられます。
- **Caution**: `MONITOR` コマンドは、高負荷時に Redis のパフォーマンスを最大 50% 低下させる可能性があります。本番環境では注意して使用してください。

### コマンドコンソール（パレット）
`Ctrl+K`（または `Cmd+K`）を押すと、**コマンドパレット**が開きます。この大幅なアップグレードにより、アプリ内で強力な CLI ライクな操作が可能になります。
- **Smart Suggestions**: 入力に応じて、主要なすべての Redis コマンドをリアルタイムで自動補完します。各コマンドの構文ヒントと簡潔な概要が含まれます。
- **Safety First (Confirmations)**: 危険なコマンド（`FLUSHALL`、`FLUSHDB`、`SHUTDOWN` など）は、誤ったデータ損失を防ぐため、実行前に明示的な確認が必要になりました。
- **Command Registry**: パレットから直接、各コマンドの Redis.io の組み込みドキュメントリンクにアクセスできます。
- **Persistent History**: コマンド履歴はセッションや接続をまたいで保存され、上下の矢印キーで過去のコマンドを素早く切り替えられます。

### Pub/Sub
**Pub/Sub** タブでは、Redis のチャンネルとパターンをサブスクライブできます。
- **Message Streaming**: 受信メッセージをリアルタイムで表示します。
- **Multiple Subscriptions**: 複数のチャンネルやパターン（例: `events:*`）を同時にサブスクライブできます。

### Slow Query
Redis のスローログを調べて、パフォーマンスのボトルネックを特定します。
- **Execution Time**: 遅いコマンドの実行にかかった時間を正確に確認できます。
- **Client Info**: どのクライアントが遅いコマンドを引き起こしたかを特定できます。

## 高度なタブ管理
専用のタブ制御で生産性を最大化します。
- **Pinning**: タブを右クリックして **Pin Tab** を選択します。ピン留めされたタブは左側に移動し、占有スペースが小さくなるため、最も重要な接続を常に表示しておけます。
- **Bulk Closing**: 任意のタブを右クリックすると、一括管理アクションにアクセスできます。
    - **Close Others**: 現在選択しているタブ以外のすべてのタブを素早く閉じます。
    - **Close All**: ワークスペース全体を 1 回の操作でクリアします。

## UI のカスタマイズ

### コンパクトモード
高密度なレイアウトを好むユーザー向けに、RedisHub は**コンパクトモード**を提供します。
- **Increased Density**: UI 全体のパディングとマージンを削減します。
- **More Data**: より多くのキーやサーバー情報を一度に画面に表示できます。
- **Toggle**: サイドバー左下の設定アイコンから有効にできます。
