# はじめに
**RedisHub: デスクトップと Web のためのプロフェッショナル Redis クライアント**

RedisHub 公式ドキュメントへようこそ。RedisHub は、Redis エコシステムのためのプレミアムでパフォーマンス重視のコマンドセンターであり、Windows、macOS、Linux 向けの**ネイティブデスクトップアプリ**として、または**集中管理型 Web アプリケーション**として利用できます。

## 基本理念

RedisHub は次の 3 つの基盤の柱の上に構築されています。
- **スピード**: 大規模なデータセットでも最適化されたデータ取得を実現します。
- **明快さ**: データを中心に据えた、クリーンで直感的なインターフェース。
- **信頼性**: あらゆる Redis 環境への安全かつ安定した接続。

## 主な機能

RedisHub は、モダンなデータベース管理のための包括的なツール群を提供します。

- **エンタープライズ接続性**: **Standalone**、**Cluster**、**Sentinel** の各アーキテクチャをネイティブにサポートします。
- **ハイブリッドデプロイ**: ネイティブデスクトップクライアントとして利用するほか、Docker でデプロイしてチーム全体で共有する Web サービスとしても利用できます。
- **高度なセキュリティ**: **SSH トンネリング**、**TLS/mTLS**、**プロキシ (HTTP/SOCKS5)** を統合サポートします。
- **高性能なブラウザー**: glob パターンやプレフィックスパターンを用いて、数百万件のキーを効率的に検索、フィルタリング、管理できます。
- **全データ型の統合管理**: Strings、Hashes、Lists、Sets、Sorted Sets (ZSets)、Streams をシームレスに管理します。
- **モダンな技術スタック**: **Scorix Framework** をベースに構築され、高性能なシステム統合には Go を、流麗な UI には React を採用しています。

[ユーザーガイド](/docs/user-guide/connections)を参照して、Redis インスタンスをプロフェッショナルに管理し始めましょう。
