# はじめに
**RedisHub: デスクトップと Web のためのプロフェッショナル Redis クライアント**

RedisHub 公式ドキュメントへようこそ。RedisHub は、Redis エコシステムのためのプレミアムでパフォーマンス重視のコマンドセンターであり、Windows、macOS、Linux 向けの**ネイティブデスクトップアプリ**として、または**集中管理型 Web アプリケーション**として利用できます。

## 基本理念

RedisHub は次の 3 つの基盤の柱の上に構築されています。
- **スピード**: 大規模なデータセットでも最適化されたデータ取得を実現します。
- **明快さ**: データを中心に据えた、クリーンで直感的なインターフェース。
- **信頼性**: あらゆる Redis 環境への安全かつ安定した接続。

## 主な機能

RedisHub は、モダンなデータベース管理のための包括的なツール群を提供します。

- **エンタープライズ接続性**: **Standalone**、**Cluster**、**Sentinel** の各アーキテクチャをネイティブにサポートします。
- **ハイブリッドデプロイ**: ネイティブデスクトップクライアントとして利用するほか、Docker でデプロイしてチーム全体で共有する [Web サービス](/ja/docs/user-guide/web-mode)としても利用できます。アクセストークンで保護することもできます。
- **高度なセキュリティ**: **SSH トンネリング**、**TLS/mTLS**、**プロキシ (HTTP/SOCKS5)** を統合サポートします。
- **高性能なブラウザー**: 部分一致・glob・正規表現のフィルターを複数組み合わせ、フィルターのプリセットも保存して、数百万件のキーを効率的に検索、フィルタリング、管理できます。
- **全データ型の統合管理**: Strings、Hashes、Lists、Sets、Sorted Sets (ZSets)、Streams、**RedisJSON** ドキュメント、**グラフ**（RedisGraph / FalkorDB、Cypher でクエリ）をシームレスに管理します。
- **組み込みツール**: 候補表示と履歴を備えた Redis コンソール、Monitor、Pub/Sub、Slow Query、そしてキースペースとメモリをプロファイルする **Analysis**。
- **安全な設計**: 接続ごとの**読み取り専用モード**はサーバー側で強制され、本番データを安心して探索できます。
- **整理されたワークスペース**: 接続のライブ状態、色、グループ、タグ、そして接続とデータベースごとのタブ。
- **モダンな技術スタック**: **Scorix Framework** をベースに構築され、高性能なシステム統合には Go を、流麗な UI には React を採用しています。

[ユーザーガイド](/ja/docs/user-guide/connections)を参照して、Redis インスタンスをプロフェッショナルに管理し始めましょう。
