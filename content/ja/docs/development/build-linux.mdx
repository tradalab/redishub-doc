# Linux 向けのビルド

Linux 用の成果物（`.AppImage`）は `scorix` CLI を使ってネイティブにビルドされます。Docker は不要です。
AppImage のパッケージングには `linuxdeploy` と GTK/WebKit の開発ライブラリが必要です。

## 前提条件

- **Go 1.26+** と **Node.js 22+** + **pnpm**
- **AppImage 用ツール** — `linuxdeploy` に加えて `libgtk-3-dev`、`libwebkit2gtk-4.0-dev`、`libfuse2`、`patchelf`、`squashfs-tools`
- **scorix CLI** — `go install github.com/tradalab/scorix/cmd/scorix@latest`

## ビルドの手順

プロジェクトのルートから実行します。

```bash
make package          # scorix package — builds the binary + wraps it into an AppImage
```

または、OS/アーキテクチャを明示的に指定するために `scorix` を直接呼び出します（CI ではこれを実行しています）。

```bash
scorix package -d . --os linux --arch amd64
```

## 出力先

- `artifacts/RedisHub-1.11.0-linux-amd64.AppImage`（バージョンは `scorix.yaml` の `app.version` に追従します）

この AppImage は、インストール不要で最近の Linux ディストリビューションであればそのまま実行できます。

> [!NOTE]
> CI は、ネイティブの `ubuntu-22.04` ランナー上で同じ `scorix package` ステップを実行します。詳しくは
> `.github/workflows/release-linux.yml` を参照してください。
