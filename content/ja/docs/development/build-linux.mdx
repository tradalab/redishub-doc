# Linux 向けのビルド

Linux 用の成果物（`.AppImage`）は `scorix` CLI を使ってネイティブにビルドされます。Docker は不要です。
AppImage のパッケージングには `linuxdeploy` と GTK/WebKit の開発ライブラリが必要です。

## 前提条件

- **Go 1.27**、**Node.js 24**、**pnpm 11.22.0** - [はじめに](/ja/docs/development/setup) を参照。
- **AppImage 用ツール** - `linuxdeploy` に加えて `build-essential`、`pkg-config`、`file`、`patchelf`、`squashfs-tools`、`libgtk-3-dev`、`libwebkit2gtk-4.0-dev`、`libfuse2`
- **scorix CLI** - `@latest` ではなく `go.mod` にピン留めされたバージョンをインストールしてください。
  [はじめに](/ja/docs/development/setup) を参照。

CI が `ubuntu-22.04` ランナーにインストールしているパッケージは次のとおりです。

```bash
sudo apt-get install -y \
  build-essential pkg-config file patchelf squashfs-tools \
  libgtk-3-dev libwebkit2gtk-4.0-dev libfuse2
curl -fsSL -o /usr/local/bin/linuxdeploy \
  https://github.com/linuxdeploy/linuxdeploy/releases/download/continuous/linuxdeploy-x86_64.AppImage
chmod 755 /usr/local/bin/linuxdeploy
```

## ビルドの手順

プロジェクトのルートから実行します。

```bash
make package          # scorix package - builds the binary + wraps it into an AppImage
```

または、OS/アーキテクチャを明示的に指定するために `scorix` を直接呼び出します（CI ではこれを実行しています）。

```bash
scorix package -d . --os linux --arch amd64
```

## 出力先

- `artifacts/RedisHub-<version>-linux-amd64.AppImage`（バージョンは `scorix.yaml` の `app.version` に追従します）

この AppImage は、インストール不要で最近の Linux ディストリビューションであればそのまま実行できます。

> [!NOTE]
> CI は、ネイティブの `ubuntu-22.04` ランナー上で同じ `scorix package` ステップを実行します。`.github/workflows/release.yml`
> が `tradalab/scorix` の再利用可能な `scorix-release.yml` を呼び出し、`v*` タグがプッシュされると `scorix.yaml` の
> すべてのターゲットを 1 つのマトリックスとしてビルドします。
